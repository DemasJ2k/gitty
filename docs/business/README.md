## How these are produced

1. Scope with the founder (budget, involvement, target, timeline).
2. Deep research: parallel source agents, concrete numbers, survivorship-bias
   flagged (`/deep-research`).
3. LLM Council review: members debate, chairman decides (`/llm-council`).
4. Record the report and the decision here.
